## 基础信息

### 扩展名称
GitHub 英语记忆助手

### 简短说明
在 GitHub 页面选词，离线查看词面义、代码语境、发音和间隔复习；无需账号，不上传内容。

### 类别建议
效率工具（以后台实际可选类别为准）

### 默认语言
简体中文

### 支持链接
`[GitHub 仓库 Issues 地址]`

### 主页链接（可选）
`[GitHub 仓库首页地址]`

## 详细说明

读 GitHub 时看到不熟悉的英语，不必切走查词。

GitHub 英语记忆助手会在你主动选中英文词或短语后，显示易理解的中文词面义、英英释义、GitHub/代码语境、记忆钩子和例句。点击扬声器可用系统英语语音朗读；点击“加入生词本”后，可以在扩展内按间隔复习。

它收录了 Git、仓库、Issue、Pull Request、GitHub Actions、安全、设置、搜索与开发高频英语等 513 个词卡，并特别覆盖常见界面词，如 Feed、Repositories、Merge queue 和 Workflow run。

### 特点

- 只在 GitHub 页面上、只对你主动选中的英文显示解释。
- 先给出中文词面义，再给出 GitHub 语境，帮助记忆而非机械翻译。
- 支持右键、浮动“解释”按钮和 `Alt + G` 快捷键。
- 支持系统英语发音、美音/英音与语速偏好。
- 生词本和复习记录仅保存在当前浏览器中。
- 不需要 GitHub 登录、Token、API Key 或任何第三方账号。

### 隐私承诺

扩展不发送网络请求，不上传网页内容、私有代码、选中文字或生词本，不使用广告、统计或远程 AI 服务。详细内容见隐私政策。

### 重要说明

GitHub 是 GitHub, Inc. 的商标。本扩展是独立学习工具，与 GitHub, Inc. 没有从属或授权关系。

## 单一用途说明

帮助中文学习者在 GitHub 页面上理解并复习其主动选中的英语术语和短语。

## 权限理由

| 权限 | 理由 |
| --- | --- |
| `storage` | 在浏览器本地保存生词本、复习进度和语音偏好。 |
| `contextMenus` | 提供右键“用 GitHub 英语助手解释并记住”入口。 |
| `https://github.com/*` | 仅在 GitHub 页面上响应用户主动选中的文本并显示词卡。 |

## 隐私披露建议

若后台询问“是否收集、传输或出售用户数据”，根据当前代码应如实选择：扩展不向开发者或第三方传输用户数据；所有生词本和偏好均本地保存。每次功能变化后都应重新核对，不能机械复用此答案。
