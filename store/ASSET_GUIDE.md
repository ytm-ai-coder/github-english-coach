# 商店视觉资产指南

## 已包含

- `../assets/icon-16.png`、`icon-32.png`、`icon-48.png`、`icon-128.png`：已接入 `manifest.json` 的扩展图标。
- `assets/icon-source.png`：图标的高分辨率源图，仅供后续制作宣传图使用，不会被打进扩展 ZIP。

图标表达的是“带代码符号的学习书签”：阅读 GitHub 英语、保存为可复习的词卡。

## 发布人仍需准备

商店必须使用真实当前产品的截图。建议在 Chrome 或 Edge 安装扩展后，在公开 GitHub 页面完成以下截图：

1. 选中词语后弹出的解释词卡。
2. 含“加入生词本”状态的词卡。
3. 弹出页的学习统计和复习入口。
4. 复习页面。

请隐藏浏览器书签、账号资料、通知、私有仓库名和任何敏感内容。不要通过设计稿伪造尚未存在的功能。

Chrome Web Store 的图标应为 PNG，并至少包含 128 × 128 尺寸；商店还需要推广图和至少一张截图。详情见 <https://developer.chrome.com/docs/extensions/develop/ui/configure-icons> 与 <https://developer.chrome.com/docs/webstore/images>。
